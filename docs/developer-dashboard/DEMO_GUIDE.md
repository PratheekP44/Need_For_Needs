# Demo guide (faculty / investors)

1. Launch app with default `BleConfig.development()` (Virtual MCU on).
2. Open Developer Dashboard (splash long-press ×5 or Settings → type `developer`).
3. **Test Mode → Run Purchase Demo** — reconnect, AUTH, OPEN_BOX.
4. Watch **Locker Matrix** box turn yellow/open and **MCU Table** update.
5. Use **Simulation Panel** for faults (door jam, low battery, busy).
6. **Packet Monitor → Export** copies JSON to clipboard.

Customer UI remains unchanged for normal flows.
