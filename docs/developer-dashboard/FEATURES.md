# Features

| Section | Purpose |
|---------|---------|
| MCU Status | Live chips for identity, BLE, auth, telemetry, counters |
| Locker Matrix | Dynamic grid from `SimulationConfig` rows×cols |
| Box Details | Full `BoxRuntime` JSON + sensors/motor |
| Packet Monitor | App↔MCU packets, filter/pause/clear/export |
| Event Log | Virtual MCU `RuntimeLogger` timeline |
| MCU Table | Variable diffs (prev → current + reason) |
| Simulation Panel | Triggers existing MCU / LockerService APIs |
| Statistics | Counters + avg latency + success % |
| System Diagram | Highlights active layer during traffic |
| Test Mode | Scripted demos (auth, open, timeout, loss, jam) |
